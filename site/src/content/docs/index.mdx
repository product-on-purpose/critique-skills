## What this is not

It does not auto-fix anything. It does not rewrite your document, and it never edits an artifact it
was asked to critique. It returns findings, and what to do about each one stays a human decision
that gets recorded as a [disposition](how-to/dispositions/).

It also does not claim to be right. It claims to be *measured*: the numbers behind every skill are
published with the run envelopes that produced them, including the cells where a skill does badly.
The worst consistency figure in the library is 0.309, and it is [on the receipts page](receipts/)
rather than in a footnote.
