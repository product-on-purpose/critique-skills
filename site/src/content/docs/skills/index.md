Every skill in this library follows the same contract. It reads one artifact, scores it
against a fixed set of permanent criterion IDs, and returns findings in the shape
`contract/critique-contract.schema.json` defines: a criterion, a lane, a severity, a
location, the evidence for it, the violation, and a fix.

Two lanes run on every artifact. The structural lane checks what can be verified without
judgement. The judged lane is the part a model has to reason about, and it is the part
the benchmark measures.

A page per skill is generated from that skill's own `SKILL.md` frontmatter, and which
skills get a page is read from `library.json`'s active set, so the site cannot disagree
with what the plugin actually ships. Each one carries the skill's rubric provenance, its
two criterion lanes, and the boundary it holds against its siblings.

Every criterion all of them score is enumerated in one place, with its lane and the rubric
it traces to: the [criteria explorer](/critique-skills/reference/criteria/). The lane split
there is counted at build time rather than typed, so it cannot drift from the skills.
