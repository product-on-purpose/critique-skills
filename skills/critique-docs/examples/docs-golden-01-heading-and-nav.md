# Configure webhook retry limits

## Step 1: Open the webhook settings

Navigate to the integrations panel and select the webhook you want to change.

## Step 2: Set the new retry limit

Enter the number of delivery attempts in the Retry limit field and click Save.

#### Confirm the retry count updated

Refresh the settings page and confirm the retry count shown matches what you entered.
