# Reset your account password

## Step 1: Open account settings

- First, open the account menu and select Settings.
- Then, choose Security from the left panel.

## Step 2: Enable two-factor authentication

- First, toggle on two-factor authentication.
- Then, scan the QR code with your authenticator app.
- Because two-factor authentication protects the account from password reuse elsewhere, we recommend turning it on now.

## Step 3: Choose a new password

- Enter a new password that meets the length requirement.
- Confirm the new password and click Save.
