Location: Section "Schedule changes", form promo code field (#s3-form-promo-label, #promo, #s3-form-promo-error)

Problem: `aria-invalid="true"` is hard-coded in the initial markup (so the field is announced as invalid before any user interaction or submission), and the error message span is not linked to the input via `aria-describedby`, so screen reader users won't hear "Error." when focused on the field; the message is also non-descriptive.
