Problem: The entry never states whether the field is required, whether there's a length limit, or what happens if the endpoint is unreachable, redirects, or returns a non-2xx status.

Location: ## signing_secret
Evidence: "The signing_secret field accepts a string used to verify the payload signature on receipt."
Problem: The signing algorithm (e.g. HMAC-SHA256), the header carrying the computed signature, and its encoding (hex/base64) are not specified, so a reader cannot actually implement signature verification from this reference.
Fix: Document the exact algorithm, the request header name, and the signature encoding used.
