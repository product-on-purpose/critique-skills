Location: Signup form, email field, first entry ("The connection dropped before this finished.") — "Predictable mistake" line
Evidence: "Predictable mistake: yes"
Problem: A dropped connection is a network/system failure, not a user mistake, yet it's classified the same way as a genuine input error; the analogous system failure in Checkout ("Something went wrong") is correctly marked "no."

Location: Signup form, email field, first entry ("The connection dropped before this finished.") — "Fires" line
Evidence: "Fires: on-blur"
Problem: On-blur fires when a field loses focus, which makes sense for validating entered content, but a dropped connection happens during a submission attempt, not when the user leaves the field.
Fix: Change the trigger to "on-submit" (or "on-submit-failure") to reflect when this error actually occurs.
