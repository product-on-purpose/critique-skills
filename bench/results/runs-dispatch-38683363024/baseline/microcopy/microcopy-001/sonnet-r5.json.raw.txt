Location: Signup form, email field — first message block, "Predictable mistake" line
Evidence: "Message: The connection dropped before this finished." paired with "Predictable mistake: yes"
Problem: A dropped connection is a transient network/system failure, not a mistake the user made, so classifying it as a "predictable mistake" is a miscategorization that conflates system failures with user error.
Fix: Change "Predictable mistake" to "no" for this entry, or if the category is meant to cover "predictable failure modes" more broadly, rename/redefine the field so network errors fit without misrepresenting user behavior.

Evidence: "Message: The expiry date on this card has passed..." paired with "Fires: mid-keystroke"
