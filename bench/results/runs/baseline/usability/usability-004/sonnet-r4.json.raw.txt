Location: Project settings section, project name text input
Evidence: <input id="project-settings-name-input" type="text" value="Q3 Roadmap">
Problem: The input has no name attribute, so if the surrounding form were submitted the project name value would not be included in the submitted data.
Fix: Add a name attribute, for example name="project-name", to the input so its value is submitted with the form.

Location: Project settings section, the icon-only control next to the Save button
Evidence: <button id="project-settings-duplicate-btn" type="button" aria-label="Duplicate project"></button>
Problem: The button has no visible text and no icon, only an aria-label, so a sighted user has no way to tell what the control does or even that it is a functioning button rather than a rendering gap.
Fix: Add visible label text such as "Duplicate" or an icon, while keeping the aria-label for screen reader users.

Location: Invite a team member section, email address input
Evidence: <input id="invite-member-email-input" type="email">
Problem: The input has no name attribute and is not marked required, so a submitted form would not carry the email value and nothing on the page indicates that an email must be entered before proceeding.
Fix: Add name="email" and a required attribute to the input.

Location: Invite a team member section, between the form and the section's closing links
Evidence: a form containing <button id="invite-member-save-btn" type="submit">Save</button> alongside a separate <a id="invite-member-continue-link" href="#invite-sent">Continue</a>
Problem: Two different controls could plausibly be the one that sends the invite, a form Save button and a Continue link, and the markup does not make clear which one actually triggers the invitation described on the next screen.
Fix: Collapse this to a single action, or clearly differentiate the two, for example by having Save perform the send and removing or relabeling Continue so its role is unambiguous.

Location: Archive confirmation section and the project archived section

Location: Notifications section, digest frequency dropdown
