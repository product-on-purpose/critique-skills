Location: "Your projects" section (#workspace-overview), the summary paragraph and the list beneath it
Evidence: "This workspace holds 5 projects, synced last week." is followed by a list of only 4 items (Support Backlog Triage, Beta Launch Plan, Partner Integration Pilot, Mobile App Revamp)
Problem: The stated project count does not match the number of items actually listed, and nothing in the visible copy explains that the list is partial, so a user has no way to tell where the fifth project went.

Location: "Open project settings" link (#workspace-overview-projects-link) and the project it opens in #project-settings
Evidence: The link text is generic ("Open project settings," not tied to any listed project), but it opens a form pre-filled with "Customer Migration," a name that does not appear anywhere in the "Your projects" list (Support Backlog Triage, Beta Launch Plan, Partner Integration Pilot, Mobile App Revamp)
Problem: A user cannot tell which project "Open project settings" will open, and the project it actually opens is not one they can see anywhere else on the page, breaking the connection between the overview and the settings screen.
Fix: Either make each listed project name a link to its own settings page, or rename the generic link to name the specific project it opens (for example "Open settings for Customer Migration") and add that project to the visible list.

Location: "Duplicate project" button (#project-settings-duplicate-btn) in the Project settings section
