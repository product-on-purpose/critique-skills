Location: Form field for route selection, line near id="topic"

Problem: The label's for attribute references "topic-alt" but the select element has id="topic", causing the label not to associate with the input.

Location: Promo code input field

Problem: The input is marked invalid with aria-invalid but does not reference the error message with aria-describedby, breaking the connection for screen readers.
