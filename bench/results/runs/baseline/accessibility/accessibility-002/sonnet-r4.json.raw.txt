Location: head, the viewport meta tag
Evidence: <meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no" id="head-viewport">
Problem: The viewport tag disables user-scalable, which prevents pinch to zoom, making the page unusable for anyone who needs to zoom in to read the content.
Fix: Remove user-scalable=no (and any maximum-scale restriction) from the viewport meta tag so users can zoom.
