Evidence: "Please correct the highlighted field. Error code: 502."
Problem: The message never says which field is wrong or what is wrong with it, and it surfaces a raw technical error code (502 normally signals a server gateway failure, not a field validation problem) to the reader with no explanation of what the code means or what to do with it.
