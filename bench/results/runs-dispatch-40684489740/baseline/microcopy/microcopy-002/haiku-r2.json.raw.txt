Location: Checkout form, shipping address — second message
Evidence: "Please correct the highlighted field. Error code: 502."
Problem: HTTP 502 is a server error (Bad Gateway), not a validation error. Users cannot fix a server error by correcting a form field.
Fix: Replace this message with guidance appropriate for a server error (e.g., "The server is temporarily unavailable. Please try again in a few moments.") and remove the suggestion to correct a field.
