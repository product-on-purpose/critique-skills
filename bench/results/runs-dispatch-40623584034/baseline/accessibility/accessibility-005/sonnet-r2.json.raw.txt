Location: `<head>` style block — `#head-style`
Evidence: `@media (orientation: portrait) { #main-content { display: none; } }`
Problem: This unconditionally hides the entire main content (including the skip-link target) whenever the viewport is in portrait orientation, which includes most phones — the primary way people would read "service announcements" on the go.
Fix: Remove this rule, or replace it with a rule that doesn't hide `#main-content` in portrait mode (e.g. only adjust layout/spacing, never `display: none`).

Location: Header nav, `#nav-link1`
Evidence: `<a href="/accessibility" id="nav-link1" style="outline:none">Accessibility</a>`
Problem: `outline:none` removes the visible keyboard-focus indicator with no replacement focus style, making the link unusable for keyboard/screen-reader users to locate — ironic given it's the link to the accessibility page.
Fix: Remove `style="outline:none"` or replace it with a custom visible `:focus` style.

Location: `#s3-form`, phone field
