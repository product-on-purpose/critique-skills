Location: `<style>` block in `<head>`
Evidence: `@media (orientation: portrait) { #main-content { display: none; } }`
Problem: This rule hides the entire main content whenever the viewport is in portrait orientation, which is the default orientation for the vast majority of mobile phone users — making the page appear completely blank to most mobile visitors.
Fix: Remove this rule, or replace it with a rule that does not hide `#main-content` based on orientation.
