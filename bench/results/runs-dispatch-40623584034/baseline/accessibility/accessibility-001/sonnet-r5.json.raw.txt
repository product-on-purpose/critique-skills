Location: `<html lang="translanguage" id="html">`
Evidence: `lang="translanguage"`
Problem: "translanguage" is not a valid BCP 47 language code, so the declared document language is meaningless to browsers and assistive technology (affects voice selection, translation prompts, etc.).
Fix: Set `lang` to the actual content language, e.g. `lang="en"`.

Location: `<title id="head-title"></title>`
Evidence: `<title id="head-title"></title>`
Problem: The page title is empty, so browser tabs, bookmarks, history, and screen readers have no name for the page.
Fix: Add a descriptive title, e.g. "Rider Service Updates".

Location: `<nav id="nav">`
Evidence: `<a href="/plan" id="nav-link1">Plan a trip</a>\n<a href="/accessibility" id="nav-link2">Accessibility</a>`
Problem: There is no "skip to main content" link before the nav, forcing keyboard and screen-reader users to tab through navigation on every page load before reaching the content.
Fix: Add a skip link (e.g. `<a href="#main-content">Skip to main content</a>`) as the first focusable element.

Location: `<div id="main-content">`

Location: `<input id="promo" type="text" aria-invalid="true">`

Fix: Add `maxlength="6"` and a `pattern` (e.g. `pattern="[A-Za-z0-9]{6}"`) matching the stated rule.
