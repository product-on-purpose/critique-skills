Location: Checkout form, payment method — second entry ("The expiry date on this card has passed..."), Fires field
Evidence: "Fires: mid-keystroke"
Problem: Whether an expiry date has passed cannot be determined until the full date is entered, so firing this check mid-keystroke will produce false-positive errors while the user is still typing.
Fix: Change Fires to "on-blur" (or on-completed-entry) so the full date is available before the passed/not-passed check runs.
