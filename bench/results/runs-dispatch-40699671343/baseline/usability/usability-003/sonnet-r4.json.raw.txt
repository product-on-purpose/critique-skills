Location: `<head>` section
Evidence: `<meta charset="utf-8">` is the only meta tag present; no `<meta name="viewport">` follows it
Problem: There is no viewport meta tag, so this page (clearly meant to represent an app screen) will render at desktop zoom/scale on mobile browsers.
Fix: Add `<meta name="viewport" content="width=device-width, initial-scale=1">` to the `<head>`.

Problem: The stated project count (4) doesn't match the number of projects actually listed (3), with no label explaining the list is a partial/"recent" subset.
Fix: Either change the count to 3, add a 4th list item, or add visible text (e.g. "Recent projects" heading) clarifying the list is a subset of the 4.
