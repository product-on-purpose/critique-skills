Location: Section 3, custom control (s3-customcontrol)
Evidence: '<div class="icon-delete" role="button" tabindex="0" aria-label="Delete item" id="s3-customcontrol">'
Problem: A div with role="button" is not properly keyboard accessible and won't respond to Enter or Space keys without JavaScript event handling.
Fix: Replace with a real button element: '<button type="button" class="icon-delete" aria-label="Delete item"><img src="/img/trash-icon.svg" alt=""></button>'

Location: Section 3, form promo code field
Evidence: '<input id="promo" type="text" aria-invalid="true">'
Problem: The aria-invalid attribute is set to "true" on page load before the user has entered or submitted anything, incorrectly signaling an error state to screen reader users.
Fix: Remove aria-invalid="true" or change to aria-invalid="false", and set to "true" only after validation fails.

Location: Section 3, form phone number field
Evidence: Label says "Phone number (required)" but input is '<input id="phone" type="tel" autocomplete="tel">'
Problem: The field is marked as required in the label text but lacks the HTML required attribute, so the browser won't enforce validation.
Fix: Add the required attribute: '<input id="phone" type="tel" autocomplete="tel" required>'
