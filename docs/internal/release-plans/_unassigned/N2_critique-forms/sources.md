# critique-forms: bibliography

Every source read for the [criterion registry draft](criterion-registry-draft.md), generated from the
research manifests on 2026-09-25. Each was read on the access date shown. Copies are kept by the
maintainer outside this repository (`_local/research/critique-forms/`, gitignored); **no copyrighted
text is committed here**. The `sha256` column identifies the exact saved copy that was read, so a
later reader can tell whether a page has changed since. Books carry an ISBN instead of a hash.

The **handle** is how the registry draft cites a source. Evidence grades are assigned per finding in
the registry, not per source, because one source can hold both a measured result and an opinion.

**75 sources.** 2 duplicate handles were merged into the source they repeat.
